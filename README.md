# **Dark Fantasy**

This is a Python project I made while learning Python.

**What it does**

Creates a text-based terminal game in which the user has to explore a mysterious world and fight off monsters to restore balance.

**Features**

* Game timer.

* Armour and weapon archetypes.

* Choose your path.

**What I learned**

* Classes and attribute handling.

* Nested loops.

* Input validation.

* Mathematical calculations.

* Timing.

* Attribute assignment.

**How to run**

Download the files and run the Python file.

**Made with**

Python
